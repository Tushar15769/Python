# Python

A collection of beginner-friendly Python programs, scripts, and small projects created for learning and practicing fundamental programming concepts.

## 📌 About

This repository contains simple Python programs covering topics such as:

* Conditional statements
* `for` and `while` loops
* Lists
* Dictionaries
* User input
* Basic mathematical operations
* Searching
* Palindrome checking
* Functions and problem solving

These programs are intended for beginners who are learning Python and want to understand programming concepts through practical examples.

## 📂 Programs

| File            | Description                                                          |
| --------------- | -------------------------------------------------------------------- |
| `Dictionary.py` | Takes marks for three subjects and stores them in a dictionary.      |
| `Even_Odd.py`   | Checks whether a given number is even or odd.                        |
| `Leap_year.py`  | Checks whether a given year is a leap year.                          |
| `Palindrome.py` | Checks whether a given list is a palindrome.                         |
| `Search.py`     | Searches for an element in a list.                                   |
| `Sum.py`        | Finds the sum of the first `n` natural numbers using a `while` loop. |
| `Voting.py`     | Checks voting eligibility based on age.                              |
| `factorial.py`  | Calculates the factorial of a number using a `for` loop.             |
| `greatest.py`   | Finds the greatest among three numbers.                              |
| `marks.py`      | Calculates a student's grade based on marks.                         |
| `movies.py`     | Takes input for three movies and stores them in a list.              |

## 🛠️ Requirements

* Python 3.x

No external libraries are required for the programs currently included in this repository.

## 🚀 How to Run

1. Install Python from the official Python website.
2. Clone this repository:

```bash
git clone <your-repository-url>
```

3. Navigate to the repository:

```bash
cd Python
```

4. Run any Python program:

```bash
python filename.py
```

For example:

```bash
python Leap_year.py
```
